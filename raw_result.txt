## 🔍 Tənqidi Rəy - HTML Kod Yoxlaması

**Ümumi Qiymətləndirmə:** Kodun ümumi strukturu yaxşıdır, lakin bir neçə ciddi problem mövcuddur.

---

### ⚠️ Təhlükəsizlik Problemləri

1. **`target="_blank"` olmadan açılan xarici linklər yoxdur** - Bu yaxşıdır, lakin:
   - **Footer-dakı linklər (`#` ilə) heç yerə getmir** - Bu, UX problemi yaradır.
   - **`rel="noopener"` yalnız bir linkdə var** - Yalnız "EULA" linkindədir, digərləri yox.

2. **`onclick="alert()"` istifadəsi** - XSS üçün risk yaratmasa da, istifadəçi təcrübəsi üçün zəifdir.

3. **Şəkillər üçün `alt` atributları var** - Bu yaxşıdır, amma `https://picsum.photos` xarici xidmətdir və şəkillər yüklənməzsə, placeholder göstərilmir.

---

### 🐛 Funksional Problemlər

1. **Theme Toggle Fəaliyyəti:**
   - `toggleTheme()` funksiyası yalnız `dark` class-ı dəyişir, amma **CSS-də `dark` class-ı üçün xüsusi dəyişikliklər yoxdur** - yalnız `dark-mode` və `light-mode` class-ları var.
   - **`light-bg` class-ı heç yerdə istifadə edilmir** - Tərif edilib, amma tətbiq edilməyib.

2. **Modal Davranışı:**
   - Modal açıldıqda `hidden` class-i silinir, amma **Escape düyməsi ilə bağlanma dəstəyi yoxdur**.
   - **`body` scroll-u bloklanmır** - Modal açıq ikən arxa plan scroll olur.

3. **Mobile Menyu:**
   - `toggleMobileMenu()` funksiyası işləyir, amma **menyu bağlandıqda hamburger ikonu dəyişmir** (X işarəsinə).

4. **Bülleten Formu:**
   - `alert()` ilə təsdiqlənir, amma **email validasiyası HTML5 ilə** edilir - bu yaxşıdır, lakin server tərəfi yoxdur.

---

### 🎨 Dizayn və UX Problemləri

1. **Neon Effektlər Overload:**
   - `neon-border`, `card-glow`, `neon-text` hər yerdə istifadə edilib - **həddindən artıqdır**, göz yorur.
   - Bəzi yerlərdə mətnin oxunması çətindir (açıq fon + neon effekt).

2. **Rəng Kontrastı:**
   - `text-gray-400` açıq modda ağ fonda çox solğundur.
   - `text-gray-600` tünd modda bəzən oxunmaq üçün çox tünddür.

3. **Responsivlik:**
   - **Hero bölməsində** `text-4xl` mobil cihazlarda çox böyükdür.
   - **Grid-də kartlar** çox yığcamdır, mətnlər kəsilir.

4. **Accessibility:**
   - **Kontrast nisbəti** WCAG standartlarına tam uyğun deyil.
   - **Focus state-lər** yoxdur - keyboard naviqasiyası üçün.

---

### 🖥️ Kod Keyfiyyəti

1. **Təkrarlanan Kod:** Navbar, footer, script-lər hər səhifədə eynidir - **ayrıca komponentlərə bölünməlidir**.

2. **CSS-inline (Tailwind CDN):** Production üçün uyğun deyil - **build prosesi tələb olunur**.

3. **Şəkillər:** `picsum.photos` random şəkillərdir - **mövzu ilə əlaqəli real şəkillər olmalıdır**.

4. **Semantik HTML:** `section` və `footer` istifadə edilib, amma **`main` elementini əskikdir**.

---

### 🔧 Əsas Tövsiyələr

| Problem | Tövsiyə |
|---------|---------|
| Theme toggle | `dark` class-ına uyğun CSS dəyişiklikləri əlavə edin |
| Modal | Escape düyməsi və fokus trap əlavə edin |
| Mobile menyu | Hamburger ikonunu X ilə əvəzləyin |
| Şəkillər | Real, mövzu ilə bağlı şəkillər istifadə edin |
| Accessibility | Kontrast və focus state-lər yaxşılaşdırın |
| Kod təkrarı | Komponentlərə bölün (React/Vue və ya partial HTML) |

---

### ✅ Nəticə

**Ümumi bal: 6/10**

Kod funksionaldır və əsas tələblərə cavab verir, lakin peşəkar səviyyədə təhlükəsizlik, accessibility və kod təmizliyi baxımından təkmilləşdirmə tələb edir. Xüsusilə theme toggle düzgün işləmir, modal UX problemləri var və kod hər səhifədə təkrarlandığı üçün davamlılıq çətindir.

**Kritik düzəlişlər edilməlidir:**
1. Theme toggle düzəldin
2. Modal üçün Escape dəstəyi əlavə edin
3. Mobil menyuda ikon dəyişikliyi edin
4. Şəkilləri real mövzu ilə əlaqəli edin
5. Kod təkrarlarını azaldın
